 # Hostel Management App with Facial Recognition

AI-generated complete hostel management system with CCTV facial-recognition attendance tracking.

## Architecture

```
├── client/          # Flutter mobile app
├── server/          # FastAPI backend
├── worker/          # Facial recognition worker
├── infra/           # Infrastructure manifests
└── docs/            # Documentation
```

## Features

- **Attendance**: Automated facial recognition via CCTV
- **Enrollment**: Face enrollment with consent management
- **Mess Management**: Meal tracking and billing
- **Leave Management**: Request and approve leaves
- **Complaints**: Submit and track complaints
- **Emergency Alerts**: SOS and emergency contacts
- **Parent Portal**: View student activities
- **Unknown Face Detection**: Alert on unrecognized individuals

## Quick Start

### Prerequisites
- Flutter SDK (>=3.0.0)
- Python 3.10+
- Docker & Docker Compose
- PostgreSQL 14+

### Local Development

```bash
# Start backend services
docker-compose up -d

# Run migrations
cd server
python -m alembic upgrade head

# Start backend
python -m uvicorn app.main:app --reload

# Start worker
cd worker
python worker.py

# Run Flutter app
cd client
flutter pub get
flutter run
```
